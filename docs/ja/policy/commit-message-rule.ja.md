# コミットメッセージルール

## フォーマット

```
<type>(<scope>): <subject>

[optional body]

[optional footer]
```

## タイプ

- `feat`: 新機能
- `fix`: バグ修正
- `docs`: ドキュメント変更のみ
- `style`: フォーマットや空白（ロジック変更なし）
- `refactor`: コード再構築（機能追加やバグ修正なし）
- `test`: テストの追加・更新
- `chore`: ビルドプロセス、依存関係更新、ツール類

## ルール

- サブジェクト行: 最大72文字
- サブジェクト: 命令形、小文字、末尾句点なし
- 例: `feat(auth): add OAuth2 login flow`
- イシューナンバーをボディまたはフッターで参照:
  `Refs: issue003`
- ボディとサブジェクトは空行で区切る
