# ドキュメント参照慣例

## 目的

必須のコンテキストとして読み込む必要のあるドキュメントを、
例や図示として言及するパスと区別するための、一貫した方法を確立する。

## 構文

`@` プレフィックスを付けたMarkdownリンクで**必須コンテキスト**を示す:

    [@docs/policy/policy.md](docs/policy/policy.md)

`@` なしのバッククォートパスは情報目的または図示のみ:

    `docs/issue/issue003.md`

## ルール

1. `@` 参照は「このファイルは進む前に必ず読み込む必要がある」ことを意味する。
2. `@` 参照は、CLAUDE.md、ポリシー、Issueドキュメント、
   スキル定義で、前提ファイルがある場合にのみ使用すること。
3. `@` 参照はプロジェクトルート相対パスを使用（先頭スラッシュなし）。
4. `docs/reference/` 内のファイルには `@` 参照をしないこと。
5. `@` 参照されたファイル自体が `@` 参照を含む場合、
   再帰的に読み込む（2レベルまで）。
6. Markdownリンク形式 `[@path](path)` はGitHubやIDEでのクリック可能なナビゲーションを保証する。
